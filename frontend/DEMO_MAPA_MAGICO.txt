┌──────────────────────────────────────────────────────────────────────────────┐
│                            EJEMPLO DE USO                                    │
└──────────────────────────────────────────────────────────────────────────────┘

  1. CARGA AUTOMÁTICA
     ════════════════
     Al abrir el mapa, se cargan automáticamente:
     ✓ Todas las rutas con coordenadas
     ✓ Marcadores de origen y destino
     ✓ Líneas conectando puntos
     ✓ Clusters si hay muchas rutas
  

  2. INTERACCIÓN
     ════════════
     Haz clic en cualquier elemento:
     
     Marcador de origen:
     ┌──────────────────────────┐
     │ 🚀 ORIGEN               │
     ├──────────────────────────┤
     │ Juliaca                  │
     │                          │
     │ 📍 Ruta: JUL-PUN-001    │
     │ 🏢 Empresa: Trans SA     │
     │ 📊 Estado: Activo        │
     └──────────────────────────┘


  3. CONTROLES
     ═════════
     
     🔗 LÍNEAS (ON/OFF)
        • ON: Muestra líneas conectando toda la ruta
        • OFF: Solo marcadores
     
     🎯 CLUSTERS (ON/OFF)
        • ON: Agrupa marcadores (recomendado > 50 rutas)
        • OFF: Muestra todos individualmente
     
     🛣️ ITINERARIO (ON/OFF)
        • ON: Muestra todas las paradas intermedias
        • OFF: Solo origen y destino
     
     🎬 ANIMAR
        • Reproduce animación secuencial
        • Efecto bounce en líneas
        • Popups emergentes


  4. ANIMACIÓN
     ══════════
     Al hacer clic en "Animar":
     
     ⚡ Línea 1: Bounce! → Popup emerge
     ⚡ Línea 2: Bounce! → Popup emerge
     ⚡ Línea 3: Bounce! → Popup emerge
     ...
     
     Cada ruta se anima secuencialmente (50ms de delay)
     Marcadores muestran popup brevemente (500ms)
